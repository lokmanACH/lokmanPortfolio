## Local Development

To run the portfolio locally:

1. Clone the repo:

```
git clone https://github.com/lokmanACH/lokmanPortfolio.git
cd lokmanPortfolio
```

2. Install dependencies (if applicable):

```
# example for a Node/React project
npm install
```

3. Start the development server:

```
npm start
```
